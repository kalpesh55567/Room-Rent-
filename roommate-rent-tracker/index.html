How to Host for Free (in 2 Minutes)

1 Method 1: Netlify Drop (Easiest - No Login / No Git)

  1. Open app.netlify.com/drop in your browser.
  2. Drag & drop the entire roommate-rent-tracker folder into the browser.
  3. Your site is live instantly with an SSL link like https://my-room-rent.netlify.app!

2 Method 2: Vercel (Fast & Free)

  1. Visit vercel.com and sign in with GitHub or Google.
  2. Deploy by importing a GitHub repository or drag-and-drop.
  3. Get a free .vercel.app domain forever!

3 Method 3: GitHub Pages

  1. Create a free repository at github.com/new.
  2. Upload index.html, styles.css, and app.js.
  3. Go to Settings → Pages, select main branch and click Save.
